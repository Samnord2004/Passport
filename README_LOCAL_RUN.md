# Инструкция по локальному запуску и туннелированию (macOS и Windows)

Данный проект представляет собой полнофункциональное приложение **«Технический паспорт объектов и календарь регламентных работ»** со встроенным Express API сервером, локальной базой данных и React SPA клиентом.

Приложение полностью подготовлено для автономного развертывания на локальном компьютере или сервере под управлением **macOS** или **Windows** с последующим туннелированием в интернет.

---

## 📋 1. Системные требования

* **Операционная система:** macOS (10.15+) или Windows (10 / 11 / Server)
* **Node.js:** версия **18.x** или новее (рекомендуется LTS 20+)
  * Скачать для Windows / Mac: [https://nodejs.org/](https://nodejs.org/)
  * Проверить установку в терминале: `node -v` и `npm -v`

---

## 🍏 2. Запуск на macOS / Linux (1 клик)

В корневой директории проекта подготовлен готовый исполняемый скрипт **`start-mac.sh`**.

1. Откройте **Терминал** и перейдите в папку проекта:
   ```bash
   cd /путь/к/папке/проекта
   ```
2. Разрешите выполнение скрипта (при первом запуске):
   ```bash
   chmod +x start-mac.sh tunnel.sh
   ```
3. Запустите скрипт:
   ```bash
   ./start-mac.sh
   ```
4. Скрипт автоматически:
   - Проверит наличие Node.js и npm;
   - Установит зависимости (`npm install`), если они еще не установлены;
   - Соберет проект (`npm run build`);
   - Предложит удобное меню:
     * **1)** Запустить только локально (`http://localhost:5000` и по локальной сети);
     * **2)** Запустить локальный сервер + **Cloudflare Tunnel** (публичный HTTPS-адрес без регистрации — *Рекомендуется*);
     * **3)** Запустить локальный сервер + **Localtunnel**;
     * **4)** Запустить локальный сервер + **ngrok**;
     * **5)** Режим разработки (`npm run dev`).

## 🪟 3. Запуск на Windows (1 клик)

Для операционной системы Windows доступны два варианта: через классический **`.bat`** файл или через **PowerShell**.

### Вариант через .bat файл:
1. Просто дважды кликните по файлу **`start-win.bat`** в Проводнике Windows.
2. Файл автоматически проверит зависимости, выполнит сборку и выведет меню выбора (локально или с туннелем).

### Вариант через PowerShell:
1. Откройте PowerShell в папке с проектом:
   ```powershell
   .\start-win.ps1
   ```
*(Если выполнение скриптов ограничено политикой PowerShell, выполните: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*.

## 🌐 4. Туннелирование: как предоставить доступ из интернета

Туннелирование позволяет безопасно открыть доступ к вашему локальному серверу специалистам и клиентам без белого IP и проброса портов на роутере.

### Вариант А: Cloudflare Tunnel (Рекомендуемый, бесплатно, HTTPS)
- **Преимущества:** не требует регистрации, автоматически выдает бесплатный защищенный SSL-сертификат HTTPS, работает стабильно и быстро.
- **Команда из любого терминала:**
  ```bash
  npm run tunnel:cloudflared
  ```
  *или напрямую:*
  ```bash
  npx --yes cloudflared tunnel --url http://localhost:5000
  ```
  В терминале отобразится ссылка вида: `https://xxxx-xxxx-xxxx.trycloudflare.com`. Передайте её пользователям.

### Вариант Б: Localtunnel
- Не требует аккаунтов:
  ```bash
  npm run tunnel:localtunnel
  ```
  *или:*
  ```bash
  npx --yes localtunnel --port 5000
  ```
  Вы получите ссылку вида `https://xxxx.loca.lt`.

### Вариант В: ngrok
- Если у вас установлен ngrok ([https://ngrok.com/](https://ngrok.com/)):
  ```bash
  npm run tunnel:ngrok
  ```
  *или:*
  ```bash
  ngrok http 5000
  ```

### Вариант Г: Доступ без интернета по локальной сети (Wi-Fi)
Сервер слушает на всех сетевых интерфейсах (`0.0.0.0:5000`).
Любое устройство (смартфон, ноутбук техника), подключенное к той же Wi-Fi сети, может открыть приложение по адресу:
```text
http://<ЛОКАЛЬНЫЙ_IP_КОМПЬЮТЕРА>:5000
```
*(Пример: `http://192.168.1.45:5000`)*.

## 💾 6. Хранение данных

1. **По умолчанию (без настроек):**
   Приложение сохраняет все созданные объекты, фотографии, графики и чек-листы в локальный файл `server/db.json`. Данные сохраняются между перезапусками сервера. Никакой сторонней базы устанавливать не нужно.

2. **Работа с PostgreSQL (опционально):**
   Если вам требуется подключить полноценный сервер PostgreSQL, создайте файл `.env` в корне проекта на основе `.env.example`:
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль
   DB_NAME=tech_passport
   ```
   Сервер при старте автоматически применит миграции и создаст все таблицы.

## 🛠️ 7. Ручной запуск (для опытных пользователей)

Если вы предпочитаете выполнять команды вручную без запуска скрипта:

```bash
# 1. Установка пакетов
npm install

# 2. Сборка фронтенда и сервера
npm run build

# 3. Запуск сервера в production режиме
npm run start:prod
# или:
NODE_ENV=production node dist/server.cjs
```

Сервер запустится на `http://localhost:5000`.
Для туннелирования в отдельном окне терминала выполните:
```bash
./tunnel.sh        # на Mac/Linux
tunnel.bat         # на Windows
```
